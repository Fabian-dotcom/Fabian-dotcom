## How I Learn

I learn primarily by building.

Instead of trying to learn a technology completely before using it, I prefer to start with a problem, build something, figure out what I don't understand, and then investigate the underlying concepts.

I'm especially interested in understanding **why something works**, not just how to make it work.

This often leads me to experiment with different approaches, languages, architectures, and technologies.
